# Image slots

Generated by `npm run photos:inventory`. Drop `<slot>.webp|jpg|jpeg|png` into `frontend/public/photos/` (Meera: `frontend/public/photos/meera/`), then run `npm run photos:optimize` (originals go to `photos-originals/`, WebP at about 1920 and 960 px wide, placeholders, contrast stats) and restart `npm run dev`. A slot with no photo shows a plain themed gradient with the glass on top; nothing is drawn. The admin content editor can set the first home picture by URL.

## Which picture each page uses

| Page | Full-window background | Framed header |
|---|---|---|
| Home (/) | scrolling: Alankar reception, Salon, Spa, Parlor (one per section, crossfade) | none |
| /salon | salon-background | salon-hero (a different picture) |
| /spa | spa-background | spa-hero |
| /beauty-parlor | parlor-background | parlor-hero |
| Booking (/customer/book) | the division being booked (salon, spa, parlor), crossfading with the theme tint; "All" = shop-background | that division's hero (a different picture), or a close crop of shop-background for All |
| Every other page: customer dashboard, bookings list, Zen Chat, wallet, packages, memberships, gift cards, shop, orders, invoices, profile; all receptionist, stylist and admin pages; login, register; For Zenotians | shop-background (Alankar reception) | none |

Every background sits under a soft veil (about 82 to 86 percent of the page colour, checked for AA against the real photos), is blurred about 10 px (about 14 px on staff pages) and is decorative (empty alt).

## Meera, the tour guide (3D character pictures, owner supplied)

PNG, JPG, JPEG or WebP, **820x1024** (4:5 portrait, about 1024 px tall), in `frontend/public/photos/meera/` as `meera-<pose>.<ext>`. Best: a cut-out on a transparent background (PNG or WebP). A picture with a plain background also works: it is shown as a rounded image with a soft theme-tinted frame and faded edges. `npm run photos:optimize` turns each into WebP (keeping transparency). The admin has no photo-upload screen yet (only image URLs), so Meera pictures are files in that folder.
