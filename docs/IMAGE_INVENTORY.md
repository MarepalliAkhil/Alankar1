# Image inventory

Generated by `npm run photos:inventory`. Only the owner's real photos are used; nothing is drawn or generated. PNG, JPG, JPEG and WebP are accepted; `npm run photos:optimize` turns each into WebP + JPG at about 1920 px and a 960 px copy (`<name>-960.webp/.jpg`) and writes the low-quality placeholders (`placeholders.json`). Originals are kept in `frontend/photos-originals/` (git-ignored); the optimized files in `frontend/public/photos/` ARE committed.
